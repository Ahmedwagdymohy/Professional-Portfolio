Chapter one: the AI platform

Incorta’s engineers needed one sanctioned way to reach language models. I deployed LiteLLM as the company-wide gateway on GCP, backed by Cloud SQL, with per-team quotas and usage tracking.

When high-volume logs crashed its dashboard, I built a central observability layer on Langfuse, ingesting OpenTelemetry traces from both gateways across projects over Private Service Connect.

Then came the agents: an on-call agent in Slack and Telegram that reads the daily builds, an AIOps API on Cloud Run that lets agents see cluster data, and a hardened build of OpenCode for the whole company.

Under them sit NVIDIA DGX Spark machines as GPU nodes in K3s, and dedicated CPU and GPU pools on GKE for GoodMem and the Reranker.
